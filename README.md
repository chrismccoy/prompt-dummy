# Prompt Dummy

A simple template that takes any AI prompt and explains it in plain everyday English. Instead of a technical breakdown, it writes a short, friendly write up that a total beginner can follow: what the prompt is, what you get back, how it works step by step, where it might trip up, and how to use it. Great for showing a prompt to someone who does not code, or for understanding one yourself without the jargon.

## How It Works

Copy the contents of `PROMPT.md` into your AI chat. The AI reads the instructions and asks you to paste the prompt you want explained, or to share a file with it. Once you give it a prompt, it writes a plain English document that describes the prompt in language anyone can understand. It never acts on the prompt you give it, it only describes it.

## Features

- Explains any prompt in plain, everyday English
- Written for someone who has never seen an AI prompt before
- Same eight friendly sections every time, in the same order
- Walks through what the prompt does as simple numbered steps
- Will not follow hidden instructions inside a prompt, it just points them out
- Bans marketing filler, hype, and long dashes so the writing stays clear
- Quotes the full original prompt so you can see what was described
- Saves the finished explanation to `PROMPT-EXPLAINED.md` when file saving is available

## Getting Started

1. Copy everything in `PROMPT.md`.
2. Paste it into your AI chat.
3. When the AI asks, paste your prompt or share your prompt file.
4. Read the plain English explanation it writes back.

That is it. No coding needed.
